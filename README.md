# القرآن الكريم

تطبيق قرآن كريم مبني باستخدام **React Native** و**Expo**، بواجهة عربية. يوفّر قراءة السور والآيات، والبحث في نص القرآن، والاستماع للتلاوة، إلى جانب أدوات يومية مثل المسبحة الإلكترونية والقبلة.

## المزايا

- استعراض سور القرآن الكريم وقراءة الآيات بخط قرآني.
- حفظ موضع القراءة والرجوع إليه لاحقًا.
- البحث في نص الآيات، مع خيارات لتحديد السورة ورقم الآية.
- تشغيل تلاوة آية منفردة أو متابعة تلاوة آيات السورة.
- عرض التفسير الميسّر أو تفسير الجلالين عند توفر اتصال بالإنترنت.
- حساب اتجاه القبلة اعتمادًا على موقع الجهاز واتصال بالإنترنت.
- مسبحة إلكترونية مع أذكار وإمكانية تعديل الذكر والعدّ.

## المتطلبات

- Node.js بإصدار متوافق مع Expo SDK 57.
- npm.
- Expo Go للتجربة على جهاز، أو محاكي Android/iOS. بعض ميزات الأجهزة، مثل اتجاه القبلة، تعتمد على توفر صلاحيات الموقع وحساس الاتجاه.

## التشغيل محليًا

من مجلد المشروع:

```bash
npm install
npm start
```

سيعرض Expo رمز QR وخيارات تشغيل المشروع. استخدم Expo Go لمسح الرمز أو اختر محاكيًا متاحًا.

## نسخة الويب وGitHub Pages

المستودع مهيأ لتصدير نسخة ويب ونشرها تلقائيًا إلى GitHub Pages عند كل دفع إلى فرع `main`:

```bash
npm run build:web
```

يُنتج الأمر الملفات الثابتة داخل `dist/`. سير عمل GitHub Actions في `.github/workflows/deploy-pages.yml` يبني هذه الملفات وينشرها. رابط المستودع المتوقع هو [KareemAbuayyash.github.io/QuranApp](https://KareemAbuayyash.github.io/QuranApp/)؛ في إعدادات المستودع، فعّل Pages واختر **GitHub Actions** كمصدر النشر. قد يحتاج أول نشر دقائق حتى يظهر الموقع.

الويب مناسب للتصفح الحديث. أذونات الموقع تحتاج HTTPS وموافقة المستخدم، أما البوصلة فقد لا تتوفر أو تختلف دقتها حسب المتصفح والجهاز. ميزات الصوت والتفسير تعتمد على دعم المتصفح والاتصال.

أوامر التشغيل المباشر:

```bash
npm run android
npm run ios
npm run web
```

يتطلب تشغيل iOS عادةً جهاز macOS مع أدوات تطوير Apple. قد يختلف دعم خصائص الجهاز بين الويب والمنصات الأصلية.

## البناء باستخدام EAS

يحتوي المشروع على إعدادات EAS في `eas.json` لملفات التطوير والمعاينة والإنتاج. بعد تثبيت أداة EAS وتسجيل الدخول:

```bash
npx eas-cli build --profile development --platform android
npx eas-cli build --profile preview --platform android
npx eas-cli build --profile production --platform android
```

استبدل `android` بـ `ios` أو استخدم `all` للبناء للمنصتين. قد تتطلب عمليات البناء إعداد حساب Expo وبيانات التوقيع المناسبة.

## بنية المشروع

```text
.
├── App.js                    # تهيئة التطبيق والتنقل بين الشاشات
├── app.json                  # إعدادات Expo والمنصات والصلاحيات
├── eas.json                  # ملفات تعريف بناء EAS
├── screens/                  # الشاشات الرئيسية
├── components/               # مكونات الواجهة وإعادة الاستخدام
├── styles/                   # أنماط الشاشات
├── services/                 # خدمات مثل جلب التفسير
└── assets/
    ├── fonts/                # الخطوط القرآنية
    ├── source/               # بيانات السور والأجزاء وملفات التلاوة
    └── quran/                # بيانات البحث في الآيات والسور
```

## البيانات والاتصال

- بيانات السور والآيات وملفات التلاوة مضمنة في `assets/`؛ تشغيل المحتوى المحلي لا يتطلب طلبًا إلى خادم للتنزيل.
- يجلب التفسير من [Al Quran Cloud API](https://api.alquran.cloud/v1).
- يجلب اتجاه القبلة من [AlAdhan API](https://api.aladhan.com/v1/qibla).
- تحتاج ميزات التفسير والقبلة إلى الإنترنت. وتحتاج القبلة أيضًا إلى إذن الموقع؛ يطلب التطبيق إذن الموقع أثناء الاستخدام.

## التقنيات المستخدمة

- Expo SDK 57 وReact Native 0.86.

- `expo-audio` للصوت و`expo-location` للموقع واتجاه الجهاز.
